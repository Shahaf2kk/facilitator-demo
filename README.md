# לוח שיבוצי מנחים — גרסת הדגמה

גרסת הדגמה של מערכת לשיבוץ מנחים למסגרות חינוכיות.

- אין שרת ואין התחברות: הכל רץ בדפדפן, והנתונים נשמרים רק בדפדפן של מי שצופה (localStorage).
- לא נשלחים מיילים. פעולות שליחה נרשמות כאילו נשלחו.
- כל השמות, בתי הספר ופרטי הקשר בהדגמה בדויים.
- בסרגל העליון אפשר לבחור לצפות בתור רכז/ת או מנחה, ולאפס את הנתונים.

---

Demo of a facilitator scheduling board. Runs entirely in the browser — no server, no login, no emails;
data is stored only in the viewer's browser. All names and details are invented.

Not for search indexing, scraping or AI training (see `robots.txt`).
